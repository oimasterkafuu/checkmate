众人拾柴火焰高。在游玩时，如果你有新想法，欢迎参与开发。

仓库与提交流程

主仓库： https://github.com/oimasterkafuu/checkmate

  1. 在 GitHub 上 fork 仓库到你自己的账号。
  2. clone 你的 fork，并创建一个只聚焦单一主题的分支。
  3. 完成功能开发后推送分支，并发起 PR。
  4. PR 描述请说明动机、实现方式、影响范围和验证结果。

本地开发与检查

项目包管理器统一使用 pnpm。

pnpm install
pnpm run lint
pnpm run format
pnpm run build
提交前建议至少确认：
  • 不混入无关改动，提交主题单一。
  • 类型检查与构建通过。
  • 静态资源和前端脚本已经格式化。

网站开发内容边界

  • 大厅、房间、回放、认证、验证码、匹配逻辑等页面与服务端行为。
  • Socket.IO 协议新增字段时，请同步更新前端消费与文档。
  • 地图生成、渲染和性能优化可在独立 PR 进行。
